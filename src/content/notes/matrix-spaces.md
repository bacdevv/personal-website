I will show you how **four matrix spaces** describe the inputs a matrix keeps, the inputs it loses, and the outputs it can produce. We will use simple rectangular matrices so you can track the dimensions in every step.

## Learning goals

- Distinguish **column space**, **row space**, **null space**, and **left null space**.
- Find the dimensions of all four spaces from a matrix shape and its rank.
- Test whether a given right-hand side belongs to the column space.

## Part A — Column and row spaces

### 72. Column space of a matrix

**Main idea.** The column space contains every combination of the columns of A. It lives in R^m for an m-by-n matrix. Its dimension is rank(A).

$$
\operatorname{Col}(A)=\{Ax:x\in\mathbb R^n\}
$$

**Worked example.** Let $A=\begin{bmatrix}1&2\\0&0\\0&0\end{bmatrix}$. Every output $Ax$ looks like $(t,0,0)^T$: the second column adds no new direction. Thus the column space is the $x$-axis in $\mathbb R^3$, with dimension $1$.

**Check yourself:** Does a matrix with three rows always have a three-dimensional column space?

<details><summary>Answer</summary>

No. It lies in R³ but may be a line, plane, or {0}.

</details>

### 73. Column space, visualized in code

**Main idea.** Plot the columns as arrows. Two independent columns can span a plane; adding a dependent column does not enlarge that plane.

$$
\dim\operatorname{Col}(A)=\operatorname{rank}(A)
$$

**Worked example.** Draw $a_1=(1,0,0)^T$ and $a_2=(0,1,0)^T$: all combinations $s a_1+t a_2$ make the $xy$-plane. Replacing $a_2$ with $(2,0,0)^T$ collapses that plane to a line.

**Check yourself:** What happens if the second column becomes 3 times the first?

<details><summary>Answer</summary>

The span becomes one-dimensional (assuming the first column is nonzero).

</details>

### 74. Row space of a matrix

**Main idea.** The row space is generated by the rows of A and lives in R^n. Row rank equals column rank.

$$
\dim\operatorname{Row}(A)=\operatorname{rank}(A)
$$

**Worked example.** For $A=\begin{bmatrix}1&2&0\\2&4&0\end{bmatrix}$, the two rows point along the same direction $(1,2,0)$, so the row space is a line in $\mathbb R^3$; rank is $1$.

**Check yourself:** Where does the row space of a 2×3 matrix live?

<details><summary>Answer</summary>

In R³; each row contains three coordinates.

</details>

## Part B — Null spaces, orthogonality and dimensions

### 75. Null space and left null space of a matrix

**Main idea.** The null space consists of inputs that A sends to zero. The left null space is the null space of $A^T$.

$$
\operatorname{Null}(A)=\{x:Ax=0\}
$$

**Worked example.** Take $A=\begin{bmatrix}1&2\\2&4\end{bmatrix}$. Solving $Ax=0$ gives $x_1=-2x_2$; hence $\operatorname{Null}(A)=\operatorname{span}\{(-2,1)^T\}$. Because $A$ is symmetric, its left null space has the same spanning vector here.

**Check yourself:** Does the null space always include zero?

<details><summary>Answer</summary>

Yes. Every linear map sends the zero input to zero.

</details>

### 76. Column/left-null and row/null spaces are orthogonal

**Main idea.** The row space is orthogonal to the null space; the column space is orthogonal to the left null space.

$$
\operatorname{Row}(A)\perp\operatorname{Null}(A)
$$

**Worked example.** The row $(1,2)$ and null vector $(-2,1)$ have dot product $-2+2=0$. This is not an accident: every $x$ with $Ax=0$ is orthogonal to each row of $A$.

**Check yourself:** Which spaces are orthogonal in the output space R^m?

<details><summary>Answer</summary>

Column space of A and left null space of A.

</details>

### 77. Dimensions of column/row/null spaces

**Main idea.** Rank-nullity splits the input dimension into directions retained by A and directions sent to zero.

$$
\operatorname{rank}(A)+\dim\operatorname{Null}(A)=n
$$

**Worked example.** For a $3\times4$ matrix of rank $2$, input nullity is $4-2=2$ while left nullity is $3-2=1$. The four space dimensions are therefore $2,2,2,1$, with their respective ambient spaces.

**Check yourself:** How many independent null directions does a 5×8 rank-3 matrix have?

<details><summary>Answer</summary>

8 − 3 = 5.

</details>

## Part C — Putting all four spaces together

### 78. Example of the four subspaces

**Main idea.** For one rectangular matrix, compare four spaces and their ambient dimensions. The ranks of the row and column spaces must match.

$$
\dim\operatorname{Null}(A^T)=m-\operatorname{rank}(A)
$$

**Worked example.** Consider $A=\begin{bmatrix}1&0&0\\0&1&0\end{bmatrix}$ of size $2\times3$. Its column and row ranks are $2$; its null space is $\operatorname{span}\{(0,0,1)^T\}$; its left null space is only $\{0\}$.

**Check yourself:** Why can the null space be nontrivial for a full-row-rank matrix?

<details><summary>Answer</summary>

Full row rank does not imply full column rank when n > m.

</details>

### 79. More on Ax=b and Ax=0

**Main idea.** Solving Ax=b asks whether b is in the column space. Solving Ax=0 finds all invisible input directions.

$$
Ax=b\text{ is solvable}\iff b\in\operatorname{Col}(A)
$$

**Worked example.** With $A=\begin{bmatrix}1&2\\2&4\end{bmatrix}$, $b=(3,6)^T$ is reachable, for example from $x=(3,0)^T$. But $b=(3,5)^T$ is not reachable because its second entry must equal twice the first.

**Check yourself:** Can a solvable Ax=b have more than one solution?

<details><summary>Answer</summary>

Yes, when Null(A) contains nonzero vectors.

</details>

## Detailed worked example

## A complete 2×3 example

I will use one small matrix throughout this chapter:

$$
A=\begin{bmatrix}1&2&0\\0&0&1\end{bmatrix}.
$$

**Column space.** The columns are $(1,0)^T$, $(2,0)^T$, and $(0,1)^T$. The first and third span all of $\mathbb R^2$. Thus $\operatorname{rank}(A)=2$.

**Row space.** The rows $(1,2,0)$ and $(0,0,1)$ are independent in $\mathbb R^3$.

**Null space.** Solve $x_1+2x_2=0$ and $x_3=0$. Every null vector is $t(-2,1,0)^T$. The nullity is $1$, so $2+1=3$.

**Left null space.** Since the rank equals the two output dimensions, the only solution to $A^Ty=0$ is $y=0$.

Check the spaces against their ambient dimensions: column/left-null live in $\mathbb R^2$; row/null live in $\mathbb R^3$. Their dimensions add up to $2$ and $3$, respectively.

## Why rank-nullity works

Choose a basis of $n$ input directions. Rank counts the directions that survive as independent output information; nullity counts input directions mapped to zero. No direction is counted twice, so the dimensions sum to $n$. More formally, this follows from the rank-nullity theorem for the linear map $x\mapsto Ax$.


## Verify the calculations with Python

The numerical examples use NumPy. Each block is self-contained so you can run it independently. If a library is still loading in the website runner, try the same code in Jupyter or Colab.

```python
import numpy as np
A = np.array([[1., 2., 0.], [0., 0., 1.]])
r = np.linalg.matrix_rank(A)
U, s, Vt = np.linalg.svd(A, full_matrices=True)
print("shape", A.shape, "rank", r)
print("column-space dimension", r)
print("row-space dimension", r)
print("null-space dimension", A.shape[1] - r)
print("left-null dimension", A.shape[0] - r)
null_vector = np.array([-2., 1., 0.])
print("A @ null_vector =", A @ null_vector)
```

## Practice questions

I recommend answering these questions before opening the solutions. A small calculation is more useful than memorizing a long definition.

1. Is the row space of an m×n matrix a subset of R^m or R^n?
2. If A is 4×7 and rank(A)=3, what are both nullities?
3. Why does row reduction preserve Null(A)?
4. What makes Ax=b consistent?

### Answers

1. R^n.
2. Nullity(A)=7−3=4; left nullity=4−3=1.
3. It multiplies A on the left by an invertible matrix, preserving Ax=0.
4. b belongs to Col(A).

## Common mistakes

- Do not confuse the number of columns with column-space dimension.
- A null-space basis belongs to the input space, not the output space.
- Pivot-column indices come from elimination; column-space basis vectors come from the original A.

## What I want you to remember

The four spaces come in orthogonal pairs. For an $m\times n$ matrix of rank $r$, their dimensions are $r$, $r$, $n-r$, and $m-r$.
